A face for your bot

Tiny, above other windows by default, and never in your taskbar or dock. The bubble opens when you point at it and closes when the pointer leaves.

Bot Widget is a desktop app. Open this page on a Mac, Windows or Linux computer.

How it works
  • Point at the face and the bubble opens with the latest answer and a field to reply; click it to keep the bubble open
  • The face is 68 pixels, and the bubble is never wider than 45% of the screen
  • By default the face stays above other windows, and on macOS and Linux it is on every desktop
  • Double-click the face to capture a screenshot for the chat
  • On macOS, Control+Option+Space opens the chat from any app
  • While it works, the bubble turns into a thought cloud
  • Right-click the face to switch bots, open Settings, and quit
What it needs

Bot Widget is the face, not the brain. It talks to OpenBot or Grok Bot. Without either, the face tells you so and points you to both.

Install

All downloads: macOS Windows Linux

On a Mac, paste this line into Terminal. It installs Bot Widget in your Applications folder and opens it, with no security warning.

curl -fsSL https://bot-widget.com/install.sh | sh

For Macs with Apple Silicon (M1 or newer).

On Linux, unpack the archive and run the installer:

tar xzf BotWidget-Linux.tar.gz
./botwidget/install.sh

Rather download the Mac app? Download for macOS, unzip, drag Bot Widget into Applications and open it. The app is not notarized by Apple, so the first time macOS says “Bot Widget” Not Opened: click Done, open System Settings → Privacy & Security, click Open Anyway, enter your password, then click Open Anyway once more. After that it opens normally.

Prefer the command line?

uv is for the command line and for development. On Linux the face stays tied to that terminal, so closing the terminal quits the face. For a start from the app menu, use the Linux download and install.sh. That command is bot-widget.

uv tool install git+https://github.com/Menziess/bot-widget
botwidget

To leave the terminal and keep the face: nohup botwidget >/dev/null 2>&1 &
