A face for your bot

Bot Widget puts your OpenBot or Grok Bot on the desktop as a small animated face. Click it to chat. Watch it think.

Download for macOS

Unzip, drag Bot Widget into Applications, then open it from Spotlight. The first time, right-click the app and choose Open.

Download for Windows

Run the installer, then find Bot Widget in the Start menu. Current releases are unsigned, so Windows SmartScreen may warn: choose More info and then Run anyway.

Download for Linux 
tar xzf BotWidget-Linux.tar.gz
./botwidget/install.sh

Then search for Bot Widget in your app menu, or run bot-widget.

Bot Widget is a desktop app. Open this page on a Mac, Windows or Linux computer.

All downloads: macOS Windows Linux

Prefer the command line?

uv is for the command line and for development. On Linux the face stays tied to that terminal, so closing the terminal quits the face. For a start from the app menu, use the Linux download and install.sh. That command is bot-widget.

uv tool install git+https://github.com/Menziess/bot-widget
botwidget

To leave the terminal and keep the face: nohup botwidget >/dev/null 2>&1 &

How it works

  • Point at the face and the bubble opens with the latest answer and a field to reply; click it to keep the bubble open
  • While it works, the bubble turns into a thought cloud
  • Scroll up at the top of a long answer to pull in the message before it
  • Right-click the face to see which bot apps it found, switch bots on and off, and open Settings
  • Settings is also where you quit the widget

What it needs

Bot Widget is the face, not the brain. It talks to OpenBot or Grok Bot. Without either, the face tells you so and points you to both.
