Privacy

Bot Widget talks to the bot apps on your own computer (OpenBot, Grok Bot). On its own it only asks GitHub (api.github.com) whether there is a newer release, and downloads that release from GitHub Releases; Check for updates on the /settings page switches that off. GitHub's privacy statement applies to those requests. Anything else, such as /feedback opening a GitHub issue in your browser, only happens when you ask for it.
